# 双分支分层 ArcFace 结构与创新点说明

本文档用于对当前认证模型的基本结构进行简洁说明，并对其核心创新点进行凝练总结，便于直接用于论文方法介绍、汇报材料或方案说明。

## 1. 基本结构概述

当前模型面向手机与手表双设备 IMU 认证场景，核心思想是：

- 将手机与手表视为两个相对独立的数据源，分别建模各自的身份信息
- 在保留双分支独立判别能力的基础上，通过跨设备融合获得更完整的联合身份表征
- 在每个分支内部进一步引入多层级 ArcFace 精炼机制，提升身份嵌入的稳定性与区分性
- 在验证阶段同时利用手机、手表、融合三路分数，并结合用户级个性化阈值完成更稳健的认证决策

从整体流程上看，模型可以分为四个部分：

### 1.1 双设备独立编码

- 手机信号进入 `mobile` 分支编码器
- 手表信号进入 `watch` 分支编码器
- 两个分支分别提取各自的身份特征表示

这样做的出发点是：手机与手表虽然记录的是同步动作，但其佩戴位置、耦合方式、噪声模式和动作响应分布并不相同，因此应被看作两个不同的信息源，而不是简单拼接后的同质输入。

### 1.2 双分支特征融合

- 在获得手机分支和手表分支特征后，模型通过注意力机制对双分支信息进行自适应建模
- 同时保留设备均值残差，避免融合结果完全偏向某一路
- 最终得到融合分支的联合身份表示

因此，模型并不是只依赖某一路设备，而是形成：

- 手机分支
- 手表分支
- 融合分支

三条并行的身份判别路径。

### 1.3 分支内部的分层 ArcFace 精炼

在每一条分支内部，模型并不是只接一个单层 ArcFace，而是引入“多层级 ArcFace + 残差调整”的串行精炼结构：

- 第 1 层 ArcFace 先对基础 embedding 施加身份判别约束
- 中间的残差适配模块对特征做小步修正
- 第 2 层 ArcFace 再对修正后的 embedding 继续施加判别约束
- 最终将基础特征与最后一级 refined feature 进行融合，得到该分支的最终身份表示

这样做的本质不是重复分类，而是利用逐层监督的方式，倒逼模型学出更稳、更干净、更有区分度的身份嵌入。

### 1.4 多路验证与个性化阈值

在验证阶段，系统不会只使用融合分支单路判断，而是同时保留：

- 手机分支得分
- 手表分支得分
- 融合分支得分

然后对三路分数进行加权融合，得到最终验证分数。

此外，不同用户并不共享同一个固定阈值，而是基于验证集为每个用户单独校准阈值。这样可以进一步吸收用户间特征分布差异，使最终决策更稳健。

## 2. 创新点凝练

下面给出适合论文或汇报中直接使用的创新点表达。

### 创新点一：面向双设备独立源建模的双分支 ArcFace 结构

我们基于手机与手表数据分布相对独立的假设，将两个设备视为两个独立身份信息源进行建模，而不是简单拼接后统一处理。

在此基础上：

- 手机分支负责提取手机侧身份特征
- 手表分支负责提取手表侧身份特征
- 融合分支通过注意力机制对双分支特征进行自适应加权融合

这一设计使模型同时具备：

- 单设备独立判别能力
- 双设备联合协同能力

从而形成一个“分支独立、融合协同、多路互补”的认证框架。

可凝练表述为：

> 提出一种面向双设备独立信息源的双分支 ArcFace 认证结构，在保留手机与手表分支独立身份判别能力的同时，通过注意力驱动的自适应特征融合获得更完整的联合身份表示，实现多路协同认证。

### 创新点二：分支内部的多层级 ArcFace 精炼机制

在传统 ArcFace 结构中，一个分支往往只对应一次身份监督。当前方法进一步在单个分支内部引入多层级 ArcFace 串行结构，并配合残差调整模块进行逐层特征精炼。

这一机制的作用在于：

- 通过多次身份约束逐步压缩类内差异
- 通过小步残差修正提升特征稳定性
- 通过最终融合获得更适合模板匹配的身份嵌入

其核心价值不在于“增加分类头数量”，而在于：

- 倒逼模型学习更有区分度的特征
- 提升认证场景下 embedding 的可分性与鲁棒性

可凝练表述为：

> 提出一种分支内多层级 ArcFace 精炼结构，通过“ArcFace 监督 + 残差修正 + 再监督”的串行机制，学习更稳定、更具判别性的身份嵌入，从而提升基于特征向量的认证能力。

### 创新点三：三路协同验证与用户级个性化阈值机制

当前系统在验证阶段保留了三条身份证据路径：

- 手机分支
- 手表分支
- 融合分支

这三路分数不是简单平均，而是通过验证集锁定最优融合权重后共同参与最终判断。

同时，系统不采用全局统一阈值，而是针对不同用户保留不同阈值。这样做相当于在特征判别之外，再增加一层用户级差异化保险，使模型能够更细致地适应不同身份的分布特征。

可凝练表述为：

> 提出一种三路协同验证机制，将手机、手表与融合分支的身份分数联合用于认证，并通过用户级个性化阈值校准吸收不同身份的分布差异，从而提升开放环境下的验证稳健性。

### 创新点四：面向新用户注册的增量式更新潜力

针对实际应用中的新用户注册场景，该结构天然适合向增量式更新机制扩展，而不必每次新增用户都对整个模型进行全量重训练。

其可扩展方向包括：

- 新用户模板增补
- 用户级阈值重校准
- 面向新注册身份的轻量微调
- 指纹库的持续更新与优化

需要说明的是：

- 当前系统已经具备模板构建与用户级阈值校准能力
- 完整的“新用户在线增量微调闭环”可作为后续工程化与论文扩展方向

因此，这一点更适合表述为“应用扩展能力”或“潜在创新方向”，而不是当前主实验的已完整闭环能力。

可凝练表述为：

> 面向实际注册场景，该框架具备向增量式身份库更新机制扩展的潜力，可通过模板更新、阈值重校准以及轻量微调实现新用户注册后的持续优化，而无需依赖全量模型重训练。
